These are the original delivery's check receipts. The
[15 November follow-up](../followup/README.md) contains the current 294-test run,
incremental PR history review and fresh environment observations. Original outputs
in this folder remain unchanged.

The files in this folder preserve the actual local check outputs and the GitHub API
responses available during delivery. They do not turn an unexecuted container or
provider job into a passing integration.

## Application tests

The clean Python **3.11.18** environment executed **110 tests, all passing**, in
4.87 seconds. See the original [pytest log](pytest.log) and [JUnit report](pytest.xml).
The suite covers strict contracts, causal features, delayed outcome availability and
ingestion, label joins, replay boundaries, numerical model identity, monitoring,
backups, malformed bytes and the pinned Kafka offset API. Unit predictors and
consumer doubles are explicit. [Ruff output](ruff.log) is preserved separately.

commits through `199b53a`, their seven parent links, 83 unique authored blobs and

matched the fetched objects. All 83 unique historical text blobs were pattern
scanned, with zero findings and no skipped blobs; one negative URL-validation fixture

worktree scanner therefore reports zero local history blobs and a null local HEAD;

fetched commit/tree objects and the exact originally submitted blob content. It
checks correspondence and ancestry, without signed-author verification. Its endpoint
precedes this final evidence-only publication, whose current files are covered by
the publication content review.

The [copy manifest](copy-manifest.json) binds original locations to the copied check
files. Hashes establish correspondence, not authorship or certification.
